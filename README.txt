DARUL QURAN W SUNNAH — FREE IPHONE OFFLINE PWA STARTER

IMPORTANT
- This version stores student, attendance, class and fee records in browser storage on this iPhone only.
- It does not send your records to a server and has no subscription fee.
- It is not installed from this ZIP directly. For offline Home Screen use, host these files on an HTTPS static host first (GitHub Pages can be free), open the published URL in Safari, then Share > Add to Home Screen.
- Open it once while online after publishing so Safari can cache the app shell. Then test airplane mode.
- Use Settings & Backup > Export Backup regularly and keep the JSON backup somewhere safe.
- If you clear Safari website data, delete the web app, or the device fails, local records may be lost. Export backups regularly.
- Do not enter highly sensitive information unless you are comfortable storing it on this phone.

FREE PUBLISHING OPTION
1. Create/sign in to a GitHub account.
2. Create a new public repository, for example darul-quran-w-sunnah.
3. Upload all files from this folder to the repository root.
4. In repository Settings > Pages, choose deploy from branch, select main and /(root), then Save.
5. Wait for GitHub Pages to provide the HTTPS website address.
6. Open that address in Safari on the iPhone. Tap Share > Add to Home Screen.
7. Open the new Home Screen icon once while online, then test offline.

This is a starter app, not a professionally audited data-security product.
